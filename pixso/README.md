# Плагины для Pixso

Создавай каждый плагин в отдельной папке `pixso/<plugin-name>/`. Храни рядом исходники, конфигурацию и README с инструкцией по запуску и упаковке. Для нового проекта можно использовать официальный шаблон Pixso.

[Руководство по разработке плагинов Pixso](https://pixso.net/developer/en/plugin-api/guide/setup.html).
