# Triplex Token Exporter

Экспортирует локальные коллекции переменных текущего файла Figma в JSON. Код готов к запуску без установки зависимостей и сборки.

## Запуск

В Figma Desktop открой дизайн-файл и выбери **Plugins → Development → Import plugin from manifest…**. Укажи `manifest.json` из этой папки. Запусти **Triplex Token Exporter** из меню Development и нажми **Скачать JSON**. Для публикации замени локальный ID в манифесте на выданный Figma.

## Проверка в редакторе

Создай в коллекции Palette с одним режимом цвет Blue/500. В коллекции Theme с режимами Light и Dark создай переменную Accent и задай ссылку на Blue/500 в Light и белый цвет в Dark. Скачай файл и сравни структуру:

```json
{
  "Palette": { "Blue": { "500": { "Value": "#0066FF" } } },
  "Theme": {
    "Light": { "Accent": { "ref": "Palette/Blue/500" } },
    "Dark": { "Accent": { "Value": "#FFFFFF" } }
  }
}
```

Альфа-канал записывается в конце HEX при непрозрачности ниже 100%. Числа, строки и логические значения сохраняют свой тип. Пустые коллекции сохраняются. Если у переменной нет значения в конкретном режиме, она пропускается в этом режиме. При недоступной ссылке или конфликте имён плагин показывает ошибку.
