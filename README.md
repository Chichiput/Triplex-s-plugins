# Triplex’s plugins

Плагины дизайн-системы Triplex для Figma и Pixso. Каждый плагин находится в собственной папке с исходниками, конфигурацией и инструкцией по запуску.

| Платформа | Папка | Плагины |
| --- | --- | --- |
| Figma | [`figma/`](figma/) | [Triplex Token Exporter](figma/token-exporter/) |
| Pixso | [`pixso/`](pixso/) | [Triplex · Библиотеки](pixso/library-manager/) |

Если один инструмент нужен в обоих редакторах, используй одинаковое имя папки, например `figma/token-exporter/` и `pixso/token-exporter/`. У каждой версии свои настройки и команды сборки.

## Разработка в ChatGPT / Codex

Открой локальный клон `Triplex-s-plugins` как рабочую папку. В задаче укажи редактор, имя плагина, ожидаемое поведение и способ проверить результат. Правила проекта описаны в [`AGENTS.md`](AGENTS.md).

> Создай плагин для Figma в `figma/layer-namer/`. Он должен переименовывать выбранные слои по заданному префиксу. Добавь README с инструкциями по сборке, запуску и проверке на нескольких выбранных слоях.

## Коммит и Push через GitKraken

1. Открой существующий локальный клон `Triplex-s-plugins` в GitKraken Desktop.
2. Для первого коммита выбери файлы структуры, нажми **Stage**, введи `Initialize plugin repository` и нажми **Commit**.
3. Нажми **Push** и выбери `origin`, если GitKraken предложит указать удалённый репозиторий для ветки.
4. Для следующих задач при необходимости создавай короткие ветки, например `figma/layer-namer` или `pixso/token-exporter`. После проверки сделай коммит, отправь ветку на GitHub и объедини изменения с основной веткой.

Инструкция по интерфейсу [GitKraken Desktop](https://help.gitkraken.com/gitkraken-desktop/guide/).

## Выпуск плагинов

Push отправляет исходники на GitHub. Для публикации в каталоге редактора используй процесс соответствующей платформы. Для распространения готовой сборки через GitHub можно создать Release с версией и приложить файл сборки.

- **Figma**. Проверь плагин через инструменты разработки Figma и отправь его на рассмотрение для публикации в Community. [Инструкция Figma](https://help.figma.com/hc/en-us/articles/360042293394-Publish-classic-plugins-to-the-Figma-Community).
- **Pixso**. Проверь плагин в Pixso и собери пакет с помощью `plugin-cli pkg`, если проект использует официальный CLI. [Документация Pixso](https://pixso.net/developer/en/tools.html).
