# Triplex Token Exporter

Экспортирует локальные коллекции переменных текущего файла Figma в JSON. Код готов к запуску без установки зависимостей и сборки.

## Запуск

В Figma Desktop открой дизайн-файл и выбери **Plugins → Development → Import plugin from manifest…**. Укажи `manifest.json` из этой папки. Запусти **Triplex Token Exporter** из меню Development и нажми **Скачать JSON**. Для публикации замени локальный ID в манифесте на выданный Figma.

## Проверка в редакторе

Создай в коллекции Palette с одним режимом цвет Blue/500. В коллекции Theme с режимами Light и Dark создай переменную Accent и задай ссылку на Blue/500 в Light и белый цвет в Dark. Скачай файл и сравни структуру:

```json
{
  "Palette": { "Blue": { "500": { "Value": "#0066FF" } } },
  "Theme": {
    "Light": { "Accent": { "ref": "Palette/Blue/500" } },
    "Dark": { "Accent": { "Value": "#FFFFFF" } }
  }
}
```

Альфа-канал записывается в конце HEX при непрозрачности ниже 100%. Числа, строки и логические значения сохраняют свой тип. Пустые коллекции сохраняются. Если у переменной нет значения в конкретном режиме, она пропускается в этом режиме. При недоступной ссылке или конфликте имён плагин показывает ошибку.

## Добавление коллекции из таблицы

Импортированная коллекция всегда называется `Components`. Вставь диапазон вместе с заголовками или открой CSV/TSV в UTF-8. Первый столбец содержит путь, а каждый следующий — значения одного режима. Пример CSV:

```csv
Токен,Light,Dark
Фон/Основной,#FFFFFF,#171717
Текст/Акцент,{Палитра/Синий/500},{Палитра/Синий/300}
```

Нажми **Добавить коллекцию**, затем **Скачать JSON**. С одним столбцом значений название режима опускается. Пустая ячейка пропускается, ссылка в фигурных скобках становится `ref`. Логические значения true/false и десятичные числа становятся соответствующими типами JSON. Импорт действует до закрытия окна плагина и добавляет данные только в экспорт.

Для проверки измени переменную в Figma и нажми **Сканировать** в открытом окне. Предпросмотр покажет новое значение, а импортированная таблица сохранится. Повторный импорт заменяет таблицу в текущем экспорте. Если в Figma уже есть коллекция `Components`, плагин сообщает о конфликте.

Для компонентной таблицы используй заголовки `component,property,type,Light,Dark`. Компонент становится папкой, свойство — именем токена, тип `ref` сохраняет ссылку в исходной записи, а `value` сохраняет текст ячейки как `Value`. Колонки без заголовка игнорируются, в том числе заметки справа. Можно вставить ячейки через буфер или выбрать файл.
