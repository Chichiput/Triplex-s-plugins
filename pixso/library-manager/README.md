# Triplex · Библиотеки

Плагин управляет подписками на библиотеки в текущем файле Pixso. Нажмите **Сканировать**. Галочка означает, что после выполнения библиотека должна быть подключена. Под названием указано её текущее состояние.

Плагин отмечает доступные библиотеки из списка 12 версий Triplex в `code.js`. При сравнении учитывается версия, игнорируются регистр и лишние пробелы. Для первой библиотеки поддерживаются оба написания префикса — `W]` и `[W]`.

Измените галочки и нажмите **Выполнить**. Поиск и фильтр **Триплекс** управляют видимостью строк. Счётчики учитывают также скрытые строки. После выполнения плагин заново читает состояние подписок. Новое сканирование сбрасывает выбор к набору Triplex.

## Сборка и локальный запуск

Файлы JavaScript и HTML готовы к запуску. Установка зависимостей и компиляция не требуются. Откройте редактируемый файл в настольном Pixso, в разделе локальных плагинов импортируйте `manifest.json` из этой папки и запустите **Triplex · Библиотеки**.

## Проверка в редакторе

1. В тестовом файле подключите одну стороннюю библиотеку и отключите одну доступную библиотеку из списка Triplex.
2. Нажмите **Сканировать**. Сверьте список и подписи состояний с панелью библиотек Pixso. Проверьте, что галочки стоят у перечисленных версий Triplex.
3. Отметьте вручную стороннюю библиотеку. Включите **Триплекс**, введите часть названия, затем очистите поиск и снимите фильтр. Убедитесь, что отметка сохранилась.
4. Нажмите **Выполнить** и сверьте подписки с панелью Pixso, включая строки, скрытые фильтром. После успешного выполнения оба счётчика должны показывать ноль.
5. Нажмите **Сканировать** ещё раз. Подписи отражают применённые изменения, галочки снова предлагают набор Triplex.
6. Если Pixso не вернул список за 12 секунд, появится сообщение об ошибке. При потере связи окна с плагином ожидание ответа завершается через 35 секунд. Кнопка **Сканировать** позволяет повторить запрос в том же окне.
