# Плагины для Figma

Создавай каждый плагин в отдельной папке `figma/<plugin-name>/`. Храни рядом исходники, `manifest.json` или инструкцию по его генерации и README с командами сборки и запуска. Для обновления опубликованного плагина используй его существующий ID.

[Документация Figma Plugin API](https://developers.figma.com/docs/plugins/).
