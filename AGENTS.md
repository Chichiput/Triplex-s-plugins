# Triplex’s plugins

Плагины дизайн-системы Triplex. Код Figma хранится в `figma/<plugin-name>/`, код Pixso — в `pixso/<plugin-name>/`. Имена папок плагинов пишутся латиницей в `kebab-case`.

- Для нового плагина используй API выбранного редактора. Если задача охватывает оба редактора, держи их точки входа и конфигурацию в отдельных папках.
- Перед изменением существующего плагина прочитай его README и конфигурацию сборки. Используй его текущие зависимости и команды сборки.
- В README каждого плагина опиши назначение, сборку, локальный запуск и шаги проверки в редакторе. При добавлении плагина внеси его в корневой каталог в `README.md`.
- После изменений запусти доступные проверки и сборку. В отчёте укажи, что проверено и какие действия нужно проверить в редакторе.
- По умолчанию пользователь делает коммиты и Push через GitKraken.
